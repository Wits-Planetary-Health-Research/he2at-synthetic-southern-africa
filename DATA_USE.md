# Data use note

By using these files you agree to the following.

- Use: teaching and methods development. Results are about methods, not about real women, real places or real HE²AT cohorts, and should not be presented as findings about them.
- Credit: cite HE²AT Center, Wits Planetary Health Research as the source in slides, code and papers.
- Code: please share the code developed with this data back with the HE²AT team.
- Papers: if a paper comes out of work on this data, the HE²AT authorship guidelines apply. Contact Craig Parker.
- Onward sharing: do not post the files publicly or pass them on outside the workshop until a licence has been agreed with the HE²AT Data Access Committee.

Every value is simulated. No record corresponds to a real person and no weather day corresponds to a real day.
